# RAG-bases-Medical-Chatbot
Built a context-aware medical chatbot using a Retrieval-Augmented Generation (RAG) pipeline to provide reliable, factually accurate responses in safety-critical healthcare scenarios.

Key Highlights

RAG Pipeline: Designed with fine-tuned embeddings and resilient Pinecone vector search to ensure robust medical information retrieval.

Accuracy Boost: Improved factual accuracy by 23% (BERTScore F1: 0.77), enhancing reliability in emergency decision support.

Safety & Trust: Applied anomaly-tolerant retrieval and factual fidelity checks to reduce risk in high-stakes patient care.

Evaluation: Validated outputs with BERTScore to measure factual alignment, ensuring trustworthiness in clinical contexts.
